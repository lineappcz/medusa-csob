# Security

The latest 0.1.x release is supported. Use [https://github.com/lineappcz/medusa-csob/security/advisories/new](https://github.com/lineappcz/medusa-csob/security/advisories/new)
to report vulnerabilities privately through GitHub. If private reporting is not
available, contact LINEAPP through its official website and ask for a private
security channel. Do not put exploit details, tokens or personal data in an issue.

Include affected versions, a synthetic reproduction, impact and suggested remedy.
There is no promised response-time SLA. Maintainers will coordinate remediation
and disclosure with the reporter. Default tests never send production data.
