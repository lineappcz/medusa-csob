# Community conduct

Be respectful, constructive and specific. Critique code and decisions, not people.
Harassment, threats, discrimination, doxxing and posting private information are
not acceptable. Maintainers may edit or remove harmful content, lock discussions
or restrict participation, explaining the reason when appropriate.

Report a conduct concern privately to a repository maintainer via the contact
listed on their GitHub profile. Never post private details in a public issue.
Security issues use SECURITY.md instead. Maintainers apply these expectations to
themselves and contributors equally and consider appeals sent privately.
